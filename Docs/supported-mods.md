# Supported Mods

## Source Engine Mods

Community-built Source Engine mods are shared and maintained on the official **Source Engine 4 Android** Discord server ([Join Discord Server](https://discord.gg/VqCx79Vp6T)).

---

## GoldSrc Engine Mods

### Xash3D FWGS (Modern Engine Build)
Compatible out-of-the-box (reference: [FWGS Supported Mod List](https://github.com/FWGS/xash3d-fwgs/blob/master/Documentation/supported-mod-list.md)):

- Afraid of Monsters
- Big Lolly
- Half-Secret
- Case Closed
- Bloody Pizza - Vendetta
- Borderlands
- Half-Life: Induction 1.2
- Redemption / Absolute Redemption
- Sewer beta
- Times of Troubles
- Half-Life: Urbicide
