# Valve-on-Android Documentation

Welcome to the official documentation for **Valve-on-Android**!

This project provides an automated, legal CLI tool for downloading Valve games (GoldSrc and Source engines) directly onto Android devices via Termux.

## Documentation Index

- 🚀 **[Getting Started & Installation Guide](getting-started.md)**: Prerequisites, Termux setup, execution instructions, and game engine configuration.
- 🎮 **[Supported Games](supported-games.md)**: Complete list of supported GoldSrc and Source games with official Steam store links.
- 🧩 **[Supported Mods](supported-mods.md)**: Supported mods for Xash3D FWGS (modern and old engine builds) and Source Engine.
- 📥 **[Engine & Client Downloads](downloads.md)**: Official download links for Android game engines, launchers, and game client APKs.
